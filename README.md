# TipsyTakedown
How about "Tipsy Takedown"? He records videos of his offbeat, booze-fueled heroics and posts them online as "Hero Lessons," combining entertainment with unconventional crime-fighting tips.

## QuickStart

pre-requisites

* docker
* docker-compose or compatible container manager
* make

`$ $PROJECT_ROOT/ make start`

if you are having a hardtime knowing where to put thins or reading the codebase refer to docs/code/structure-architecture.md
